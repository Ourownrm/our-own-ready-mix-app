Customer module — Android-style app icons

The customer portal Home, redrawn so its actions look like the Administrator dashboard: coloured rounded-square app icons with a white glyph and a label, in a phone app-grid — instead of the current flat cards. Same actions, same permissions; only the look changes.

What changes: each Home action becomes a coloured app tile (64 px rounded square, white line-icon, label beneath), three across, with an optional count badge — exactly the visual language of the admin dashboard's module tiles. The bottom tab bar (Home / Orders / Track / More) stays. Nothing about what a customer can see or do changes — tiles still appear only for the permissions that customer has (tracking, QC reports, technical writings).

Notes on the design

Each action keeps a fixed colour so it becomes recognisable by shape and hue — the same idea as the admin modules. Counts (orders on file, trucks en route, an unpaid statement) sit as a small badge on the corner.
The grid is three-across on a phone and reflows wider on a tablet, exactly like the admin grid. Icons are the app's own line-glyph set drawn in white — no images, so they stay crisp and load instantly.
Delivery Notes, Statements and Contact Us are shown here as examples of how easily the grid takes new actions later; the current build ships My Orders, New Order, Live Tracking, QC Reports and Technical Writings, each still gated by the customer's own permissions.
