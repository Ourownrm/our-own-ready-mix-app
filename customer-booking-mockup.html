Same pattern the app already uses for customer delivery-tracking links: an unguessable token scoped to exactly one customer + one site, no login required. Manager or Administrator creates it once per project and shares it over WhatsApp/SMS — the customer never sees or picks any other customer's data.

Off by default — turn on per customer/site if you want tracking bundled into this same link instead of sharing a separate one.
