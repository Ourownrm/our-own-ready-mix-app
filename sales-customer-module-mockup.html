MOCKUP v5 — for review only, not wired to live data. Latest changes: the visit/follow-up report moves into the existing Sales Performance page instead of a new one; the customer booking link now allows multiple open requests per site instead of blocking a second one while the first is pending; customer name is now big and bold above the site name on that page; the leads visit questionnaire is answered inline and Save stays disabled until it's complete.

What's changing

Guiding principle for this rework (per your note): the Sales Executive's screen should push them to do the three things that actually grow the business — visit more sites, respond to leads fast, and keep forecasts current so Operations can plan around them — not bury those under admin screens for booking/feedback that belong elsewhere.

Today — Sales Executive's own screen

Dashboard · Bookings · My leads · Visits · Feedback — 5 tabs, plus a separate link out to Forecast
Booking form lives here, disconnected from the Customer Booking Links screen Manager/Admin use
Feedback is its own tab, unrelated to which visit it came from
A visit can be saved with zero follow-up created if no rule condition fires
No visibility into which days had no site visits at all — under-visiting isn't flagged anywhere
Multiple follow-ups on the same customer show as separate unrelated items, no shared thread or action history

Proposed

Sales Executive: Leads · Visits · Forecast — 3 tabs, one purpose each
Booking moves into the Customer module; Feedback folds into recording a Visit (optional field)
New: achieved sales (m³), outstanding payments, and a "sites overdue a visit" count on the landing KPIs

New: follow-ups group into one thread per customer/visit with a logged action history, reported in Reports → Sales
New: lead update makes the visit questionnaire mandatory when "Site visit" is the update type — answered inline, Save stays disabled until every question is answered
New: "My leads" shows who sent each lead; forecast changes now notify Operations, same push pattern as owners'-meeting/technical-visit requests
New: visit cadence & follow-up thread report is added to the existing Sales Performance page, not a new report
New: customer booking link allows multiple open requests per site (e.g. different grade/qty combos) instead of blocking a second one while the first is pending
